# SilicoCycle: VLSI Circular Economy & Sustainability Platform ♻️🔌

SilicoCycle is an automated, gate-level sustainability analysis platform designed to evaluate and score integrated circuit (IC) designs for environmental compliance, recyclability, and circular economy metrics. 

By parsing gate-level netlists (specifically targeted at the **SkyWater Sky130** standard cell library) and coupling them with an **Analytic Hierarchy Process (AHP)** multi-criteria decision-making model, SilicoCycle estimates material footprints, tracks toxicity hazards, and generates corporate-grade PDF compliance reports.

---

## 🚀 Features

* **Yosys JSON Ingestion:** Seamlessly parses gate-level netlists generated by the open-source Yosys synthesis suite.
* **Phase 1.5 Dynamic Material Model:** Automatically scales material masses based on cell footprints, drive-strength multipliers, and logic function categories (e.g., arithmetic, routing, clock-trees).
* **SQLite Materials DB:** Maintains a pre-populated repository of common chip-making materials, complete with density, RoHS status, End-of-Life (EOL) recycle rates, and toxicity scores.
* **AHP-Derived Weighted Scoring:** Employs an Analytic Hierarchy Process (AHP) eigenvector method to weight competing criteria (Toxicity, Recoverability, Disassembly) with a perfect consistency ratio ($CR = 0.000$).
* **Ellen MacArthur Foundation MCI:** Evaluates resource linearity versus circularity using the Material Circularity Indicator (MCI) framework.
* **Interactive Web Dashboard:** Modern, glassmorphic UI using Flask and modern CSS, featuring live animated gauge meters, responsive progress bars, and dynamic, context-specific engineering recommendations.
* **Corporate PDF Generator:** Leverages ReportLab to stream formal, multi-page compliance reports on demand.

## ⚙️ Installation & Setup

### Prerequisites
* Python 3.9+
* Pip (Python package manager)

### Quick Start

1. **Clone and navigate to the repository:**
   ```bash
   git clone https://github.com/yourusername/silicocycle.git
   cd silicocycle
   ```

2. **Install the required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Initialize the SQLite database:**
   ```bash
   python database_init.py
   ```
   *This bootstraps the materials metadata (Silicon, Copper, Aluminum, Silicon Dioxide, Gold, lead-Sn solder, etc.).*

4. **Start the Flask web server:**
   ```bash
   python app.py
   ```

5. **Open your browser and navigate to:**
   👉 **`http://127.0.0.1:5000`**

* **`iot_sensor_controller.json`** (~3.8k cells): Low power, low metal footprint, high silicon proportion.

* **`fpu_ieee754.json`** (~23.3k cells): Math-heavy arithmetic logic with high drive strength, dense copper routing.
* **`gpu_shader_core.json`** (~72.4k cells): High complexity layout with heavy clock distribution networks.

## 🧪 Mathematical Engine Specifications

### 1. Analytic Hierarchy Process (AHP)
Multi-Criteria Decision Analysis (MCDA) weights are derived dynamically from a reciprocal pairwise comparison matrix across three key metrics: **Toxicity**, **Recoverability**, and **Disassembly**.
The principal eigenvector resolves to:
* **Toxicity:** $\approx 40\%$
* **Recoverability:** $\approx 30\%$
* **Disassembly:** $\approx 30\%$

$$\text{Consistency Ratio (CR)} = 0.000$$

### 2. Material Circularity Indicator (MCI)
Evaluates flow circularity based on virgin material inputs ($V$) and unrecovered waste output ($W$) against total product mass ($M$), using the Ellen MacArthur utility coefficient ($F(X) = 0.9$):

$$\text{LFI} = \frac{V + W}{2M}$$
$$\text{MCI} = 1 - \text{LFI} \times 0.9$$
